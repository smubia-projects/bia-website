# Scout report: award-site study (Opal, Getty Persepolis, Mana Yerba Mate, impeccable.style)
(For Wave 9 Fable touch-up pass. All values measured, not eyeballed. Screenshots in session scratchpad.)

## Opal (op.al) — ultra-restraint product/editorial
- ONE typeface (Die Grotesk C). Only THREE font sizes on the whole page: 42.7 / 18.3 / 16px.
- Heading 700 @ ~1.10 leading, slightly POSITIVE tracking (+0.02em). Hero:body only ~2.3:1 — restraint reads as confidence.
- Zero accent color — photography is the color. White on black.
- Footer: giant "opal" wordmark as near-black-on-black dot-matrix halftone texture (~2% lighter than bg); minimal right-aligned link row with wide even gaps.

## Getty — Persepolis Reimagined (immersive editorial)
- Culturally-matched display serif (tells the story before you read); Graphik for UI. ~4 sizes total.
- Cinematic loading: "100" counter in gold filigree ring. Scroll drives a WebGL camera.
- ONE gold accent rationed brutally: ring, counter, circular-button hairlines only. NEVER on text.
- Circular icon buttons = 1px gold hairline rings, no fill. Film grain for atmosphere.

## Mana Yerba Mate (playful brand — most relevant to a lively club site)
- One grotesque (Neue Montreal) but ~18:1 size range (291px → 16px). 
- INVERSE weight scaling: giant words are THIN (300), mid headings BOLD (700). Big-and-light.
- Ink near-black rgb(14,14,14), never #000.
- One saturated field color per section; sections divided by ORGANIC CURVED WAVES, not rectangles; product straddles section seams for depth.
- Pill buttons radius 40px; icon buttons full circles; cards rotated a few degrees (hand-placed feel), tab-headers protruding, copy set on arcs.
- Shadows ONLY on floating controls (carousel arrows).
- Footer = interactive mini-game ("Press Space to jump") — footer as play.
- Sticky nav chips; illustrations parallax; product photos stay crisp and still.

## impeccable.style (craft showcase — deepest study)
- Display: Alumni Sans 81.6px weight 100 (THIN), tracking -0.01em, leading ~1.02, color oklch(0.91) near-white (never pure). Signature: huge + condensed + ultra-thin + tight.
- Body: Albert Sans 16.8px weight 300, leading ~1.6.
- Eyebrow: UPPERCASE, tracking ~+0.15em, gold.
- Hero:body ~4.9:1 but thin weight keeps it elegant.
- STRICT two-tone accents: gold = brand + primary CTA + active nav + eyebrows; teal = hyperlinks + section numbers. Never mixed roles. Gold at mid-lightness/high-chroma works on BOTH themes.
- SHADOWS: box-shadow none everywhere. Depth = gold kintsugi veins texture + 1px hairline borders + thin vertical dividers + layered panel lightness.
- Radii near-sharp: CTA 2px, chips 4px. Primary CTA: gold fill, near-black text, 0/28px padding, no shadow, weight 500, inline → arrow.
- Micro: tiny mono section numbers ("07") in teal; gold-hairline "BETA" chips; mono code chips; segmented pill toggle; links = offset underline + trailing arrow; dotted-hairline footer divider.

## Cross-site patterns
1. Radical size restraint (3-4 sizes) OR radical range (18:1) — never the mushy middle (6-8 undifferentiated sizes = generic).
2. Near-black/near-white, never #000/#fff.
3. One accent rationed brutally; at most a second accent with ONE distinct job.
4. Display leading ~1.0-1.1; body ~1.6.
5. The footer is a designed statement, not a sitemap dump.
6. Depth is earned — a whole theme can run on borders + texture with zero shadows.

## Top 12 transferable moves for SMUBIA
1. Cap type scale to ~5 sizes with obvious jumps (hero ~4rem / section ~2.25rem / card 1.25rem / body 1rem / eyebrow 0.75rem); delete in-betweens.
2. Bricolage hero BIG and LIGHT: clamp(3rem→6rem), weight 300-400, -0.02em, line-height 1.02 — big-and-thin, not big-and-black.
3. Body Inter ~1.05rem/1.6; consider weight 300 for large intro paragraphs on pine anchors.
4. Never pure black/white — hold the existing tinted line (#12352C ink, #0C211C pine, #F6FAF8 base).
5. Two-tone accent discipline: mint = brand/primary CTA; sand = links/eyebrows/section numbers (or vice-versa) — never swap jobs.
6. Roboto Mono eyebrows UPPERCASE ~+0.15em tracking; emerald on light / mint on dark.
7. Number sections with tiny mono labels ("01 / 02…") in accent.
8. ONE radius stance everywhere — for a student club: friendly pills (999px) on nav chips/CTAs + slightly rounded cards (Mana), not a random mix.
9. Card depth via 1px pine-tinted hairline borders; ONE soft diffuse shadow reserved for floating/hover controls only; flat sections stay shadowless.
10. Divide pine anchors from light sections with an organic curve or texture band; let one element straddle the seam.
11. Statement footer: oversized low-contrast SMUBIA wordmark texture (Opal) or dotted-hairline divider (Impeccable) above a clean link bar.
12. Exactly ONE intentional non-grid gesture per page (card rotated 2-3°, arc text, hover easter egg). One is craft; ten is chaos.
